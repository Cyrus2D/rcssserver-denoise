Findings

Which improvements held up?

Self position

Exp2 removed about 27% of paired live position error.

Fresh player position

Exp3 and Exp6 reduced error with frequent observations, under different noise models.

Unseen player position

Exp5 removed about 62% of paired error below 50 m. Match results did not improve reliably.

For gameplay, check when players act on the estimate. Motion after kicks, age and command order all mattered.
