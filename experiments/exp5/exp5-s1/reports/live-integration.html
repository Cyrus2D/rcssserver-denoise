Exp5-S1 live integration

Ready for a live trial. The frozen practical policy is implemented in librcsc and Helios, built and installed. Default operation is off. The default active counter policy preserves the real observation age.

What is applied

  • GRU128 wmresidual128_l1, 32 cycles of 51 causal features and uniform-number embedding; boosted-tree strong_cost selector; strict score >0.8.
  • Output: another player's current x,y. Apply selected predictions on valid stale known-player tracks, named-sighting age 1–30, during continuous PlayOn. Fresh count-zero positions, ball, self, velocity and body stay stock.
  • Only Exp5 unquantized, finite-view, no-hear/no-fade conditions are supported. Unsupported settings log a status and fall back to WM. Fullstate is labels only. No true-distance gate or true state enters the model.
  • Model files/inference/history are in Helios. Librcsc supplies the hook, decision overlay, refreshed geometry/interception and paired logging.

The offline independent baseline-game confirmation below 50m was 134.98 → 52.30 cm mean error; 3.64% added >25cm error and 1.70% added >50cm. Rare severe regressions remain (up to 11.82m added). Those are offline results, not a live win-rate forecast. No extra correction cap was added to the selected policy.

Zero is not an actual sighting. It removes some stale-position penalties and changes age-based action/view/interception gates. Test it in a separate batch; do not mix its results with preserve. seenPosCount is never reset. The next sensor fusion and model input use the original tracker state in both modes. Predictions are removed after action/debug output and before future fusion. Histories reset across stoppages, setplays and cycle discontinuities.

  • Native inference vs PyTorch on 256 frozen calibration windows: max output position difference 0.00000581m; selector score difference <1e-15; zero routing disagreements. The 21-target CPU microbenchmark was about 10.6ms median.
  • All 51 live input features were reconstructed from the same raw logged observations on both sides and in both age policies. Floating-point tolerances are 3e-6 absolute +3e-7 relative; max observed difference was 3.82e-6.
  • 1,056 sampled live outputs were also compared with the original PyTorch pipeline: max position difference <0.000071m (including four-decimal output logging), zero selection disagreements. Boosted-tree scores are sensitive to tiny float differences at split thresholds: max score difference 0.0334, retained as a diagnostic rather than described as exact score parity.
  • Actual posCount matched the chosen policy for every applied smoke row. Shadow/off never applied; fresh positions were not replaced. Overlay tests verify unchanged raw/seen ages, corrected geometry and clearing before the next raw update. Unsupported quantized mode never activated in 11 agents.
  • CPU live inference medians were about 10–12ms; p95 about 18–22ms, observed maximum 34ms on this machine. These are inference times, not complete action times or a guarantee under large parallel loads. No CUDA or PyTorch runtime.

Final duplicate-track regression check

A fourth match (final-duplicate-guard, left apply/zero, right shadow) passed after ensuring duplicate uniform-number tracks use the same lowest original age in encoder, application and logger matching. It finalized all 22 observers, applied 10,854 corrections, reconstructed 63,294 feature rows, and matched another 528 PyTorch outputs with zero routing disagreements. The maximum position difference remained below 0.000071m. The final binaries include this guard. Preparation of schema-4 zero-count logs was also tested: training inputs retain the original player ages, not the effective zeros. No missing-decision placeholder rows occurred in the three primary checks.
