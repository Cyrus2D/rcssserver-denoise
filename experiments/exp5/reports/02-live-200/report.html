What happens when vision is incomplete?

Exact visible measurements, limited view, ordinary world-model prediction. This report measures the error that remains when observations become old.

Read this distinction first. Sensor noise is an error in a measurement received now. Prediction error is the difference between the current world model and the true state while information is old. Turning off quantization removes the first; it cannot reveal unseen dash, turn, kick, collision or random physics outcomes.

What the main numbers say

  • Self position error averages 1.841 cm at position count 1 and 2.236 cm at count 2. Use the separate self scale when reading the plots.
  • Teammate/opponent position errors are 24.509 / 24.066 cm at count 1, rising to 112.082 / 116.472 cm at count 5.
  • Ball position error is 19.112 cm at count 1 and 302.654 cm at count 5. Unseen motion changes make its long-gap behavior different from player motion.
  • Count-0 player outliers and missing old velocity/body fields are explained below. They must be handled explicitly when building a prediction dataset.

A fresh ball position can still have an old velocity

On current ball sightings with position count 0, mean velocity error was 0.1367 cm/cycle, with a maximum of 4.902423 m/cycle. A fresh position alone is insufficient evidence that velocity was observed. Keep field-specific masks and counters in the later predictor.

One example: game 202611151205_13776, observer right 11, cycle 1891 (PlayOn). The ball was 2.799137 m away and its position was fresh, but both raw motion fields were absent. The retained velocity had count 2 and error 4.902423 m/cycle. This is an old velocity estimate rather than a noisy raw velocity reading.

At cycle 1891 the orange square restores position to zero error while velocity remains wrong. Subsequent unseen position predictions drift again. The near-field ball was outside the view cone and supplied no motion fields. Saved case rows.

2. Self between visual fixes

Each bar uses the available valid errors on decisions with or without a see update. These are descriptive cohorts. A see update is not necessarily a successful self-position fix: it can update face without providing a usable position landmark. Exact sense-body speed does not make global velocity exact if the estimated looking direction has drifted. Successful fresh visual position fixes are checked separately above.

Example: observer right 5, game 202611151202_8681, cycle 3924 received a narrow-view see message, with exact face and velocity, but no new self-position fix. Position count remained 1 and position error was 9.3963 cm; the previous successful fix at cycle 3923 was exact. This is missing position information, not sensor quantization.

7. Distance and age together

The distance filter uses the true distance from observer to target at that cycle. In exact mode, distance should not create a quantization floor for fresh measurements. Larger errors at older ages reflect motion, visibility and tracking, rather than distance quantization.

8. How often are errors large?

Mean error alone can hide a small set of costly mistakes. These plots show the proportion among valid logged fields above explicit reference thresholds; invalid/missing tracks are excluded, not counted as successes. Thresholds are reporting aids, not calibrated decision safety margins.

A concrete association failure

Game 202611151200_20018, observer left 9, cycle 1262 (PlayOn). Opponent R3 was not seen, yet its stored track had position count 0 and was 7.357442 m from its true position. The track coincided with the exact anonymous localization of nearby opponent R5 (within CSV coordinate rounding). R5 was outside the view cone but within the native near-field visibility distance. Source inspection explains the mechanism: PlayerObject::updateBySee retains the old uniform number when an anonymous observation has no uniform number, while replacing position and resetting its count. The shaded sector shows the actual 120-degree cone. Truth labels in this diagnostic are for explanation only.

10. What this baseline tells us to try next

  1. Preserve confirmed fresh measurements. There is no quantization error here to denoise again. Concentrate prediction on missing or stale fields.
  2. Separate identity failures from motion errors. Reusing a stale uniform number for an anonymous close player can create a large error even at count 0. A motion predictor should retain identity confidence and reset on uncertain associations.
  3. Evaluate player motion at each gap age. Use whole-game train/validation/test splits and compare against the existing WM and causal constant-velocity baselines on identical rows. Preserve the large-error rates, not just the overall mean.
  4. Treat ball motion changes as a separate regime. Unseen kicks, tackles and collisions invalidate simple inertia. Use only causally available possession/context features, and report near-self and post-action cases separately before live application.
