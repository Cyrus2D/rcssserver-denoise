How much error remains in a fresh measurement?

Raw relative position is the observed polar vector compared with the true polar vector in the observer's own frame. Its Euclidean error excludes observer position and orientation error. Raw-error comparisons use unambiguous uniform-number matches. Exp1's long-distance entries can represent a different and much smaller subset even inside the same distance bin. The librcsc relative estimate uses its estimated looking direction to rotate the visual vector into global axes. It still excludes observer position error.

Fresh visual position versus the world model

Across available tracks, mean error went from 1.595 to 0.800 m. Fresh raw relative error at 10–20 m was nearly the same, 39.60 and 39.54 cm. The gain in tracking accuracy came with much better coverage while substantial fresh measurement error remained.

Both estimates use the same player and cycle within each run. They are scored in global coordinates, so observer localization also affects them.

First denoising test

  1. Keep identity fixed and start with position. Compare raw polar decoding, librcsc's fresh visual estimate, and a constant-velocity predictor on the same samples.
  2. Add a temporal filter that scores candidate positions with the server's forward quantizer. Protocol v19 rounds bearing to the nearest degree. Distance uses a logarithmic step of 0.1 and a final 0.1 m rounding. When focus is displaced, the forward model uses distance to the observer and distance to its focus point. Use the agent's own focus and pose estimates. Treat identical consecutive readings as the same quantization constraint until the relative geometry changes.
  3. Split by whole match. Evaluate both relative and global error against fullstate by distance and motion availability. Fullstate supplies labels and diagnostics. The filter consumes only observations and the agent's own state estimates.

A single quantized range can represent multiple true distances. Changes in relative geometry across cycles are what can narrow that interval. Check whether the filter beats constant velocity before adding a learned motion prior.

Server measurement check

On 206,703 identified player observations from one agent in each of two Exp3 games, replaying the server's distance quantizer with logged true geometry reproduced 206,700 ranges. Rounding the true bearing to the nearest degree reproduced 206,672 bearings modulo 360°. Both sampled agent streams had zero focus distance throughout PlayOn. This check uses fullstate to verify the sensor formula. In a live filter, candidate states and the observer's estimated focus supply the geometry.
