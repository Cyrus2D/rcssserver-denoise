In Exp2 the left-minus-right difference was -0.20 goals per game (95% interval -0.70 to +0.28) and +0.03 points per game (95% interval -0.51 to +0.57). The intervals show how uncertain the match effect is. Since the model always played left, these games cannot separate its effect on results from a side effect.

Method

Player and object metrics pool eligible PlayOn samples with equal weight. The paired self comparison uses live decision logs. Cross-run tables use the same filters as the full reports. Match intervals resample whole games 10,000 times. Position error is the distance between the estimate and the server position.
